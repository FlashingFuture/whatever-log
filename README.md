# whatever.log

> 뭐라도 하겠지.

PC에서 실행 중인 프로세스와 활성 창을 주기적으로 기록하고, 사용자가 설정한 목표·일정과 비교해 **AI 기반 일일 요약과 목표 달성 연관성**을 제공하는 앱입니다.

> 상태: MVP 설계 단계

---

## 핵심 기능 (MVP)

- **프로세스 기록**: 15~30초 간격으로 활성 창과 실행 중인 프로세스를 기록
- **기록 조회**: 일·주 단위 사용 시간, 앱·카테고리별 분포, 시간대별 타임라인
- **목표 & 캘린더**: 목표를 설정하고 캘린더에 관련 일정을 배치
- **AI 일일 요약**: 하루 기록을 요약하고, 목표와의 연관성을 분석

---

## 프로젝트 방향

### 1. 모노레포
기록 에이전트, 앱 UI, 공통 로직을 하나의 저장소에서 관리합니다. 실행 단위(앱)와 재사용 단위(패키지)를 나누고, 공통 타입과 규칙은 한 곳에서 정의합니다.

### 2. 확장성 있는 설계
- **역할별 분리**: 수집 · 저장 · 집계 · 요약 · UI는 서로의 내부 구현을 몰라도 동작하도록 경계를 둡니다.
- **교체 가능한 구성 요소**: 저장소, AI 제공자(외부 API / 로컬 모델), 수집 방식은 인터페이스 뒤에 두어 나중에 바꿀 수 있게 합니다.
- **필요할 때 추가**: 지금 필요하지 않은 기능과 추상화는 미리 만들지 않습니다.

### 3. 가독성 우선
- 영리한 코드보다 읽히는 코드를 택합니다.
- 이름만 보고 역할을 알 수 있게 짓습니다.
- 디렉터리 구조만 봐도 앱의 흐름이 보이게 둡니다.

### 4. 로컬 우선
기록은 기본적으로 사용자 기기에 저장하고, 민감한 정보는 외부로 보내지 않는 것을 기본값으로 합니다.

## 구조 (초안)

```
.
├─ apps/        # 실행 단위 (예: 데스크톱 앱)
├─ packages/    # 재사용 단위 (예: 수집, 집계, AI 요약, 공통 타입)
├─ docs/        # 설계 문서, 아키텍처 다이어그램
├─ .claude/     # Claude Code 설정
│                 settings.json: PreToolUse로 민감 파일(.env, secrets.*) 편집 차단,
│                 PostToolUse로 수정된 파일에 포매팅 자동 적용
├─ .husky/      # Git hooks (pre-commit)
│                 커밋 직전 lint-staged로 lint·포매팅 최종 검증
├─ .mise.toml   # Node 버전 제약 (mise). 로컬에서 바로 느껴지는 버전 체크용
├─ Dockerfile   # 개발 컨테이너 이미지 정의 (Node 버전 고정)
└─ docker-compose.yml
                  Dockerfile로 빌드한 컨테이너에 리포를 마운트해서 실행.
                  node_modules/pnpm store는 별도 volume으로 분리해
                  호스트(Windows)와 컨테이너(Linux)가 서로 안 건드리게 함
```

세부 구조는 구현하면서 정합니다.

## 개발 환경

- **Node**: 24.x LTS (`package.json`의 `engines.node`, `.mise.toml` 참고)
- **패키지 매니저**: pnpm — `corepack enable` 후 `pnpm install`
- **Lint/Format**: `pnpm lint`, `pnpm format` (Biome)
- **버전 관리(로컬)**: [mise](https://mise.jdx.dev/)로 Node 버전만 고정해뒀습니다 (`.mise.toml`). `mise install`로 맞는 버전을 받고, `mise activate`를 쉘 프로필에 추가하면 디렉터리 진입 시 자동 전환됩니다.
- **Docker**: `docker-compose.yml` + `Dockerfile`로 개발 환경을 컨테이너화할 수 있습니다. 앱 빌드용이 아니라 여러 디바이스에서 동일한 Node 버전을 보장하는 용도입니다. `docker compose run --rm dev bash`로 들어가서 작업하면 됩니다. (빌드/실행 검증 완료)
