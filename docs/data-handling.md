# 데이터 처리 방식

whatever.log가 어떤 데이터를 모으고, 어디에 두고, 무엇을 밖으로 보내는지 정리한 문서입니다.
기본 원칙은 하나입니다. **기록은 이 PC 안에만 있고, 밖으로 나가는 것은 사용자가 요청한 AI
보고서에 쓰는 집계 수치뿐입니다.**

> 이 문서의 "예정" 표시는 아직 구현되지 않은 계획입니다. 구현되면 표시를 지우고, 계획이
> 바뀌면 이 문서를 먼저 고칩니다. 외부 전송은 구현 전에 이 문서의 내용과 일치하는지 확인합니다.

## 1. 이 PC 안에서만 오가는 데이터

아래 데이터는 이 PC의 로컬 DB(`recorder.db`)와 로컬 캐시에만 있고 어떤 외부 서비스로도 보내지
않습니다.

| 데이터 | 언제 모으나 | 어디에 두나 | 용도 |
| --- | --- | --- | --- |
| 포그라운드 프로세스 이름 | 15초마다 | `recorder.db` | 활성 시간 집계 |
| 창이 떠 있는 프로세스 목록 | 15초마다 | `recorder.db` | 유휴·백그라운드 시간 집계 |
| 마지막 입력 후 경과 시간 | 15초마다 | `recorder.db` | 활성/유휴 판정 (키 입력 내용은 기록하지 않음) |
| 실행 파일 경로 | 프로세스를 처음 볼 때 | `recorder.db` | 프로세스 아이콘 추출 |
| 프로세스 아이콘 | 화면에 처음 표시할 때 | `apps/hub/icon-cache/` | 화면 표시 (PNG 캐시) |
| 활성 사이트 도메인 | 지원하는 브라우저가 포그라운드일 때 15초마다 | `recorder.db` | 사이트별 사용 시간 |
| 사이트 아이콘 | 화면에 표시할 때 | 저장하지 않음(hub 메모리에만 잠시) | 화면 표시 |

모으지 않는 것:

- 키보드 입력 내용, 화면 내용(스크린샷), 클립보드
- 페이지 제목, URL의 경로·쿼리·해시 (사이트는 **도메인까지만** 저장합니다)
- 시크릿 창의 방문 (브라우저가 방문 기록을 남기지 않아 자연히 제외됩니다)
- 지원하는 브라우저가 아닌 앱의 창 제목 (창 제목은 지원하는 브라우저가 포그라운드일 때만 읽습니다)

### 사이트 정보를 얻는 방법

지원하는 브라우저(Chromium 계열: **Chrome, Edge, Brave, Vivaldi**)가 포그라운드일 때 창
제목으로 방금 본 페이지를 찾아 도메인만 뽑습니다. Firefox, Opera 등은 지원하지 않습니다. 이
과정에서 그 브라우저의 방문 기록을 **읽기 전용 복사본으로만** 읽고, 원본은 건드리지 않습니다. 복사본은
임시 폴더에 두었다가 recorder가 종료될 때 지우고(비정상 종료로 남았으면 다음 실행 때 지웁니다),
읽은 내용 중 도메인만 남기고 나머지(제목·경로)는 저장하지 않고 버립니다. 브라우저 확장
프로그램은 설치하지 않습니다.

이 방식은 **추정**입니다. 같은 제목의 다른 사이트(새 탭 등)나 방문 기록에 아직 없는 페이지는
틀리거나 도메인 없이(없음) 기록될 수 있습니다. 얼마나 맞는지 보려고 recorder 로그에 "브라우저가
포그라운드였던 틱 수 / 도메인을 찾은 틱 수"만 남깁니다(도메인·제목은 로그에 남기지 않습니다).

#### 사이트 아이콘

브라우저가 이미 저장해 둔 아이콘(설치된 브라우저들의 프로필에 있는 `Favicons`)을 읽기 전용
복사본으로 읽어 화면에 보여 줍니다(복사본은 읽고 바로 지웁니다). **사이트로 요청을 보내지 않고**, 제3자 아이콘
서비스도 쓰지 않으므로 외부 네트워크 요청이 없습니다. 아이콘은 디스크에 따로 저장하지 않고
hub 메모리에만 잠시 둡니다 — 브라우저 기록을 지우면 이 PC에 사이트 흔적이 남지 않습니다.
브라우저에 아이콘이 없는 사이트는 도메인 첫 글자로 대신 표시합니다. 기록된(recorder가
저장한) 도메인에 대해서만 아이콘을 찾습니다.

## 2. 밖으로 나가는 데이터 (예정)

외부로 나가는 경로는 **사용자가 AI 보고서 생성을 요청할 때** 하나뿐입니다. 전 틱(15초 단위
기록)이나 프로세스·사이트 이름은 보내지 않고, 이 PC에서 **마스킹·집계한 값만** 보냅니다.

### 실제로 전송되는 내용

| 항목 | 예 | 설명 |
| --- | --- | --- |
| 기간 | `2026-11-03`, 일/주/월 | 어느 구간의 보고서인지 |
| 목표 이름 | `공부`, `업무` | 사용자가 직접 만든 목표 이름 |
| 설정 목표량 | `120분` | 사용자가 그 목표에 정한 시간 |
| 실제 달성 시간 | `95분` | 그 목표에 매핑된 활동의 활성 시간 합 |
| 달성률 | `79%` | 달성 시간 / 목표량 |

프로세스·사이트가 어떤 목표에 속하는지는 사용자가 이 PC에서 정하는 매핑이고, 매핑 자체는
보내지 않습니다. 서버는 "공부 목표 120분 중 95분(79%)"만 받으며, 그 95분이 어떤 앱이나 사이트에서
나왔는지는 알 수 없습니다.

### 전송되지 않는 내용

- 프로세스 이름, 실행 파일 경로, 사이트 도메인, 아이콘
- 시각별 기록(틱), 창 제목, 페이지 제목, URL
- 사용자를 식별하는 값(이름, 이메일 등)은 보고서 요청에 담지 않습니다. 요청 인증에 필요한
  값이 생기면 이 문서에 먼저 적습니다.

### 사용자가 통제하는 부분

- 기본값은 **외부로 보내지 않음**입니다. 보고서 생성은 사용자가 직접 요청할 때만 동작합니다.
- 전송 전에 위 표와 같은 내용이 무엇인지 사용자에게 보여 줍니다.
- 목표 이름은 사용자가 쓴 글이라 민감한 문구가 들어갈 수 있습니다. 목표 이름도 전송되는
  내용에 포함된다는 점을 보고서 요청 화면에서 알립니다.

## 3. 데이터를 지우려면

- 기록: `apps/recorder/recorder.db`(와 같은 이름의 `-wal`, `-shm` 파일)를 삭제하면 모든 기록이
  사라집니다. recorder를 먼저 종료하세요.
- 아이콘 캐시: `apps/hub/icon-cache/` 폴더를 삭제하면 다음에 다시 만듭니다.
- 서버에 전송된 보고서 데이터의 보관·삭제 정책은 서버를 구현할 때 이 문서에 추가합니다.
