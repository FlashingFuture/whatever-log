# 발신 도메인과 등록업체 선택 (결정 기록)

보고서 메일(`docs/mail-design.md`)을 사용자의 받은편지함에 도착시키려면 **내가 소유한 도메인**이 필요하다. 이 문서는 어떤 도메인을 어디서 샀고 왜 그렇게 정했는지 남긴다 — 나중에 등록업체를 바꾸거나 비용을 다시 따질 때 근거가 된다.
가격·정책은 2026-11 시점의 조사이고 자주 바뀌므로, 다시 판단할 때는 각 업체의 현재 페이지를 확인한다.

## 결정

| 항목 | 결정 |
| --- | --- |
| 등록업체 | **Cloudflare Registrar** |
| DNS | Cloudflare DNS(무료, 등록하면 자동으로 쓴다) |
| 도메인 확장자 | **`.com`** (예산·평판·단순함 기준 1순위) |
| 도메인 이름 | `whateverlog.com` (Resend 인증 완료, 지역 도쿄) |
| 메일 서비스 | Resend(무료 플랜). 도메인 연결은 `wrangler.toml`의 `MAIL_FROM_DOMAIN` 한 줄 |

## 배경과 기준

- 메일 발송은 서버(Cloudflare Workers)가 중개하고 서비스(Resend)가 보낸다. Resend는 **내가 소유한 도메인을 인증(SPF·DKIM)해서** 보낸다. 도메인이 없으면 가입한 계정 주소로만 보낼 수 있는 샌드박스만 쓴다.
- 판단 기준은 셋이다: **비용**(가능한 한 싸게, 월 환산 $1 미만), **편의**(설정 단계가 적고 이미 쓰는 Cloudflare 스택과 맞는다), **메일 도착률**(스팸함으로 가면 기능의 목적이 사라진다).

## 비교한 선택지

| 선택지 | 비용 | 장점 | 단점 | 결론 |
| --- | --- | --- | --- | --- |
| **Cloudflare Registrar + `.com`** | 연 약 $10.4(원가, 갱신가 동일) | 마진·갱신 인상이 없다. WHOIS 개인정보 보호가 무료로 켜져 있다. DNS가 같은 대시보드라 Resend의 SPF·DKIM 레코드를 바로 붙인다. | 도메인 전용 서비스이고 Cloudflare DNS를 써야 한다. 지원 확장자가 430개 안팎이라 일부 국가 도메인은 없을 수 있다. | **채택** |
| 다른 등록업체(Porkbun, Namecheap 등) | 첫해만 싼 경우가 있고 갱신가는 오른다 | 첫해 가격 | 갱신가 인상, DNS를 결국 Cloudflare로 옮기는 번거로움 | 이 규모에서는 이득이 작아 제외 |
| `.dev` / `.app` | 약 $8~12(갱신 약 $12) | 개발자 서비스에 어울리고 https가 강제된다 | `.com`보다 비싸다 | 후보였으나 `.com`이 더 싸고 무난 |
| `.xyz` / `.top` / `.click` 등 싼 확장자 | 약 $1~11 | 싸다 | 스팸 발송에 많이 쓰여 **수신함 도착률이 나쁠 수 있다** | 메일 도메인으로는 제외 |
| 무료 도메인·서브도메인(eu.org 등) | $0 | 돈이 들지 않는다 | 승인제·회수 위험, 공용 접미사의 평판, 메일용 레코드 허용 여부가 서비스마다 다르다(확인하지 못한 곳이 많다), 내 도메인이 아니라 옮기기 어렵다 | 서비스의 핵심 기능(메일 도착)에 걸린 위험 대비 절약이 월 $0.9 정도라 제외 |
| `*.workers.dev` | $0 | 이미 있다 | Cloudflare 소유라 메일 인증 레코드를 넣을 수 없다 | 불가 |

## 이유 (한 줄씩)

1. **가장 싸고 예측 가능하다.** 원가 판매라 갱신해도 가격이 오르지 않는다. 연 약 $10.4는 월 약 $0.87이다.
2. **가장 편하다.** 등록·DNS·(나중의) Workers 연결이 한 계정에서 끝난다. Resend가 주는 레코드를 같은 화면에서 붙여 넣으면 인증이 된다.
3. **메일 도착률을 지킨다.** 평판이 나쁜 확장자와 무료 공용 접미사를 피하고, 내가 소유한 `.com`으로 SPF·DKIM·DMARC 정렬을 맞춘다.
4. **되돌리기 쉽다.** 발신 도메인은 `MAIL_FROM_DOMAIN` 한 줄이라, 나중에 도메인이나 등록업체를 바꿔도 코드는 그대로다(다만 도메인이 바뀌면 발송 평판은 새로 쌓인다).

## 비용 요약

| 항목 | 비용 |
| --- | --- |
| 도메인(`.com`) | 연 약 $10.4(구매 화면에서 최종 확인) |
| Cloudflare DNS | $0 |
| Resend(무료 플랜) | $0 — 월 3,000통·하루 100통, 도메인 3개까지 |
| Workers·D1(무료 플랜) | $0 — 한도에 닿으면 청구가 아니라 차단 |
| **합계** | **월 약 $0.9** |

`docs/mail-design.md`의 한도(`LIMITS`)가 무료 한도보다 낮게 잡혀 있어, 사용량이 늘어도 청구가 생기기 전에 코드가 먼저 멈춘다.

## 구매와 연결 절차

1. **계정 준비** — Cloudflare 계정에 2단계 인증을 켠다(도메인을 뺏기면 메일 발송 신뢰도까지 잃는다).
2. **도메인 검색·구매** — 대시보드 → *Domain Registration* → *Register Domains*에서 이름을 검색한다. `.com`으로 가용 여부와 가격(등록가 = 갱신가)을 확인하고 구매한다. WHOIS 개인정보 보호는 기본으로 켜져 있다.
3. **자동 갱신 확인** — 도메인 설정에서 *Auto-renew*가 켜져 있는지 본다(놓치면 도메인과 함께 메일 발송이 멈춘다). 결제 수단 만료일도 확인한다.
4. **DNS 활성 확인** — 도메인이 *Active*(Cloudflare DNS 사용)로 보이는지 확인한다.
5. **Resend에 도메인 추가** — Resend 대시보드 → *Domains* → *Add Domain*에 구매한 도메인을 넣으면 SPF·DKIM(·DMARC) 레코드를 알려 준다.
   (Resend가 Cloudflare의 자동 연결을 지원하면 한 번에 끝나고, 아니면 아래 6번처럼 직접 넣는다.)
6. **Cloudflare DNS에 레코드 추가** — *DNS → Records*에 Resend가 알려 준 레코드를 그대로 넣는다(대개 DKIM용 TXT, 반송 처리용 MX·SPF TXT). **프록시(주황 구름)는 끄고 *DNS only*로 둔다** — 메일 레코드는 프록시할 수 없다.
7. **인증 확인** — Resend에서 *Verify*를 누른다(DNS 전파에 몇 분~몇 시간). 상태가 *Verified*가 되면 끝이다.
8. **서버 설정** — `apps/server/wrangler.toml`의 `MAIL_FROM_DOMAIN = "내도메인.com"`으로 채운다. 발신 주소는 `reports@내도메인.com`이 된다. 운영 배포에는 `wrangler secret put RESEND_API_KEY`가 필요하다.
9. **시험** — 시험 메일(`POST /mail/test`, 절차는 `docs/mail-design.md`)을 보내 받은 메일의 *원본 보기*에서 `spf=pass dkim=pass dmarc=pass`를 확인하고, **받은편지함으로 갔는지 스팸함으로 갔는지** 기록한다.
10. **기록** — 이 문서의 "도메인 이름" 칸을 채운다(채움).

## 위험과 다시 판단할 조건

| 위험 | 대응 |
| --- | --- |
| 갱신을 놓쳐 도메인을 잃음 | 자동 갱신 + 결제 수단 만료 알림. 잃으면 메일 발송이 멈춘다. |
| Cloudflare 계정 탈취 | 2단계 인증, 도메인 이전 잠금(Registrar Lock) 유지. |
| `.com` 가격 인상 | 원가 연동이라 업계 전체의 인상일 때만 오른다. 큰 폭이면 이전을 검토한다. |
| 새 도메인의 도달률이 낮음(처음엔 흔하다) | 발송량을 천천히 늘리고 DMARC를 `p=none`으로 시작해 리포트를 본다. 스팸함으로 가면 SPF·DKIM 정렬과 본문(링크·수신 거부 표기)을 먼저 점검한다. |
| 월 발송이 무료 한도(3,000통)를 넘음 | 다이제스트로 묶고 시각을 분산한다. 그래도 넘으면 Resend 유료나 Cloudflare Email Service(Workers Paid $5/월)를 비교한다 — 도메인 선택과는 독립이다. |

**재검토 조건:** 월 비용이 $5를 넘게 되거나, 이 도메인의 도달률이 지속적으로 나쁘거나, Cloudflare가 정책·가격을 바꿀 때.

## 참고

- 비교 근거: Cloudflare Registrar 가격·정책 페이지, 등록업체 비교 글, Resend 요금·한도 문서(2026-11 조사). 일부 숫자는 자료마다 달라 구매 화면의 최종 가격을 기준으로 한다.
- 발송 구조와 한도: `docs/mail-design.md`. 사용자에게 보이는 데이터 취급: `docs/data-handling.md`.
